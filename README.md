# Haliç Köprüleri

DOT2103 Masaüstü Oyun Tasarımı dersi için tasarlanan 2–4 kişilik kutu oyununun tanıtım sayfası.

Fatih ve Beyoğlu ekipleri Haliç'in iki yakasından köprü kurmak için yarışır. Kendi köprüsünün sekiz parçasını karşı kıyıya ilk ulaştıran ekip kazanır.

- Kutu, kart, tahta ve kitapçık tasarımları Figma'dan dışa aktarılmıştır (`img/figma`).
- 3D Haliç sahnesi [three.js](https://threejs.org) ile çizilir.
- Kart resimleri kamu malı 19. yüzyıl eserleridir (Wikimedia Commons).

Yerelde çalıştırmak için:

```bash
python -m http.server 5173
```
